# ADR 0012 — Fundamental-led equity valuation: index PE-TTM percentile over NAV percentile, with a divergence advisory

**Status:** Accepted (2026-06-03, valuation-grounding item 001 Phase 1).
**Builds on:** [ADR 0010 — CN-fundamentals provider seam](0010-cn-fundamentals-provider-seam.md) (the 3-method Protocol this deliberately does NOT extend), [ADR 0009 — consensus-upside degrade-to-None](0009-consensus-upside-degrade-to-none.md) (the `consensus_upside_pct` `core_dca` veto this preserves), [ADR 0005 — advisory-gaps field](0005-advisory-gaps-field.md) (the non-blocking advisory channel the divergence code routes to).
**Spec:** `docs/superpowers/specs/2026-06-03-fundamental-valuation-grounding-design.md`; item spec `docs/2026-06-03-valuation-grounding/items/001-spec.md`.

## Context

The equity `valuation_state` (`classify_valuation`, `opportunity/states.py`) was decided by a **price/NAV self-history percentile** — where today's NAV ranks within its own trailing series (`self_history_percentile`). That is a price-level / mean-reversion signal, not a fundamental valuation; the classifier's own comment concedes "drawdown alone is NEVER evidence of cheapness." Every fundamental hook the architecture anticipated was inert in production: `earnings_yield`/`real_yield_10y` were never populated, `consensus_upside_pct` is honestly `None` (ADR 0009), and `pe_ttm`/`pb` were fetched **latest-row only** then used reason-only. Meanwhile `fetch_cn_index_valuation` already hit legulegu's full PE/PB series and threw the history away.

This ADR records a derivation change a future reader will otherwise re-litigate: it changes **how** the broad-index equity `valuation_state` is derived (and therefore what risk inherits), makes several non-obvious calls (a units/geography trap, an ingest-vs-provider-seam boundary, a no-live-fetch cached read), and resolves a real fundamental-vs-price trade-off.

## Decision

1. **The index PE-TTM historical percentile is the PRIMARY equity valuation anchor; the NAV percentile is the fallback.** For recognised broad-index CN vehicles (`tracked_index ∈ _BROAD_INDEX_KEYS`, 9 keys), `classify_valuation` bands on `valuation_percentile_fundamental` (PE-TTM percentile via `self_history_percentile` over the cached series) using the **existing** thresholds. When that percentile is `None` (any vehicle without ≥30 cached PE points — QDII, sector themes, active funds, or an empty table) it falls back **byte-for-byte** to the NAV `valuation_percentile_self`. The regression suite for NAV-only funds is the proof. Risk inherits the grounded verdict with **no change** to `derive_position_risk_level` (Q4 — a mean-reversion risk driver is deferred).

2. **History is AkShare-only ingest infra, NOT a 4th provider method (R4).** `fetch_cn_index_valuation_history` keeps the full legulegu series and is called **only** by the ingest-stage writer `ingest_index_valuation_history`, which upserts the `index_valuation_history(index_key, date, pe_ttm, pb, dividend_yield)` DuckDB table. The `CnFundamentalsProvider` Protocol stays 3-method; ADR 0010 and the provider tests are untouched. A Tushare history fallback is a future enhancement.

3. **The opportunity stage reads the cached table — no live fetch (R3).** `populate_inputs` reads `index_valuation_history` (latest row → `pe_ttm`/`pb`/`dividend_yield` + `earnings_yield`; full series → the percentiles); the prior `provider.fetch_index_valuation` live call is **removed**. The `provider` parameter is retained for API stability and so the no-live-fetch test can prove the index path never touches the network — it is no longer consumed by the index path. This keeps the CLAUDE.md cached-evidence invariant (`irc opportunity` never fetches live) intact.

4. **`real_yield_10y` lands in ratio units via the nominal equity-bond gap, NOT US TIPS (R1).** The `expected_real_return_positive` anchor compares `earnings_yield = 1/pe_ttm` (a ratio) against `real_yield_10y`; the CN 10Y ingest emits **percent** units, so a naive wiring made the anchor always-false. Phase 1 populates `real_yield_10y = cn_10y_yield / 100` (the 股债利差 nominal yield-gap, a standard CN allocation reading), switching to `(cn_10y_yield − cpi_yoy) / 100` if/when a CN CPI-YoY series is ingested. `real_yield_10y_tips` (US TIPS, percent units) is **never** reused — wrong geography and units.

5. **PB corroborates but never decides (Q5); divergence is advisory, never blocking (R2).** `valuation_percentile_fundamental_pb` only appends a cyclical-earnings caveat to the reason (`PE cheap` but `PB ≥ .70`); it never notches the state. When the fundamental and NAV percentiles disagree (different band tier OR `|gap| ≥ 0.25`), the single detector `valuation_divergence_code` emits `valuation_price_fundamental_divergence` — registered in `ADVISORY_GAP_CODES`, routed to `advisory_gaps`, **never** `evidence_gaps`. `classify_valuation` uses the detector for a reason note only (signature stays `(state, reason)`); `build_opportunity_row` folds the code into the gap stream before `_partition_gaps`.

6. **The consensus-upside `core_dca` veto is preserved (R5).** When the PE-percentile anchor says cheap but the (latent) `valuation_fundamental_signal` says rich, the row still drops to `small_watch`, not `core_dca` — trailing PE percentile and forward analyst target are independent fundamental lenses; their disagreement warrants a watch. `valuation_state` itself stays cheap (AC3). No change to `compose_opportunity_state`.

## Consequences

- **Blast radius is bounded to broad-index CN vehicles.** QDII (legulegu is A-share-only — Q3 defers them), sector themes, active funds (Phase 2 look-through), bonds, and gold are unchanged by construction. This is **index-level** grounding; per-A-share `pe_ttm`/`pb` remain out of scope.
- **Determinism and purity preserved:** the classifier and `populate_inputs` helpers stay side-effect-free; all network I/O is in the new ingest fetcher. The percentile is deterministic (`self_history_percentile`, rank-inclusive, `<30 → None`).
- **Citation/gate invariants untouched:** `valuation_percentile_fundamental` / `_pb` are plain numeric inputs (no `ThesisEvidence`, no `[ref:...]`), and the divergence code is advisory. The dual-coverage gate, citation selector, SAME-3, H3 partition (`evidence_gaps == ()` predicate), 16-hex citation id (ADR 0001), and Policy B / `thesis_state` ownership (ADR 0003) are structurally unaffected. `valuation_state` is a separate axis from `thesis_state` and never leaks into Policy B.
- **All-`None` dormancy lock holds:** with no cached `index_valuation_history` rows, every fundamental input is `None` and the outputs are byte-identical to the NAV-only path.
- **Negative / latent:** the lit `expected_real_return_positive` anchor now reads a nominal yield gap labelled as "real" until CN CPI is ingested (an honest Phase-1 approximation, recorded so a reader does not mistake it for a true real yield). The retained-but-unused `provider` parameter on `populate_inputs` is deliberate (test seam + API stability), not dead-code to be removed.

## Addendum (2026-06-05) — Phase D: active-fund holdings look-through now populates the slot

Decision #1 and the first Consequence above scoped the fundamental anchor to **broad-index CN vehicles** and listed "active funds (no `tracked_index`)" as falling back to the NAV percentile "by design (Phase 2 look-through)". **Phase D (PR1 spec `docs/superpowers/specs/2026-06-04-phase-d-active-lookthrough-design.md`; run `docs/2026-06-04-phase-d-lookthrough-pr1/`) builds that Phase-2 path and PR2 turns it on.** This addendum records the change; the original decisions are otherwise unchanged.

- **Active CN equity funds with no `tracked_index` now get `valuation_percentile_fundamental[_pb]` from a holdings look-through**, feeding the *same* `classify_valuation` slot and thresholds — an active fund's fundamental percentile is the same numeric input an index fund's already is. The series is a **current-basket harmonic earnings-yield** roll-up: current top-N A-share weights applied to each holding's *past* per-stock PE/PB history (per-date renormalized, §3.4), percentiled via `self_history_percentile`. It is **not** the fund's true historical PE (we don't store historical holdings) — an honest "current-basket" series; the caveat rides the diff report and every consuming surface.
- **New per-stock fetch/ingest sibling** of the index path: `fundamentals/akshare_stock_valuation.py` (EastMoney `stock_value_em` — note `stock_a_indicator_lg` is **absent** in AkShare 1.18.60, contrary to the original sketch) + `tushare_stock_valuation.py` fallback → `stock_valuation_history(stock_code, date, pe_ttm, pb, …)` DuckDB table via `data/stock_valuation_ingestor.py`. The heavy refresh is a **dedicated `irc fundamentals stock-valuation` command** (own cadence, NOT in `irc run`); `irc opportunity` reads the cached table only — the no-live-fetch invariant (R3) holds for the active path exactly as for the index path.
- **The maturity gate is the same single source of truth** (`MIN_PE_POINTS=120` ∧ `MIN_PE_DAYS=180`, now defined in `opportunity/lookthrough_valuation.py` and re-exported from `inputs_loader`; the index path calls the identical function). PB stays on the bare `<30` floor (`pb_uses_pe_gate: false`), matching the index path. **The `inputs_loader` active-fund branch is guarded by `tracked_index is None`** so enhanced-index `cn_equity_fund`s keep the index path untouched.
- **Invariants unchanged, by the same structural argument:** `valuation_percentile_fundamental[_pb]` are plain numeric inputs (no `ThesisEvidence`, no `[ref:...]`), and the divergence advisory routes to `advisory_gaps`. The dual-coverage gate, SAME-3, H3 partition, citation id (ADR 0001), and Policy B / `thesis_state` ownership (ADR 0003) are structurally untouched — verified for the flag both off and on. `valuation_state` stays a separate axis from `thesis_state`.
- **Rollout (config-flag gated, `active_fund_lookthrough` in `valuation_buckets.yaml`).** PR1 shipped `enabled: false` → all-`None` dormancy lock → prod byte-identical. **PR2 (2026-06-05) sets `enabled: true`, `coverage_floor: 0.50` (gate-#5 decision).** Gate #4 (live `stock_value_em` column confirmation) PASSED; gate #5 (the user reviewed `irc lookthrough-diff` on real cached data and chose the 0.50 floor) signed off. Recorded impact: at floor 0.50, **40 active funds grounded**; the flips are systematically one-directional (NAV-momentum-expensive → PE-cheaper). On a real `irc opportunity` before/after, 3 active funds changed `valuation_state` and **1 (`110022 易方达消费行业`) moved `small_watch → core_dca`**, with row/card/rejection counts identical (H3/SAME-3 intact). See `docs/2026-06-04-phase-d-lookthrough-pr1/gate5-review-note.md`.
- **Reach is modest and honest (spec §11):** the ceiling is funds that clear the floor *and* the 120/180 maturity gate, not all 383. The `coverage_floor` is config-tunable; the diff report's sensitivity table (0.40→71, 0.50→40, 0.60→17) sizes the precision-vs-coverage trade.
- **Still out of scope:** HK/US per-stock valuation sources (those holdings stay uncovered → floor), a latest-PE freshness probe in `irc run`, and any change to `derive_position_risk_level` (Q4 deferral stands).
