## Top-level acceptance (from source §3 design principles + execution order)

1. **CN equity funds** — for unthemed and themed `cn_equity_fund` (e.g. `005827`), `thesis_cards.yaml` carries `lookthrough_kind=="active_fund"`, `lookthrough_key=="fund_005827"`, `thesis_state ∈ {intact, under_pressure, falsified}` driven by top-stock evidence, `thesis_evidence` ≥3 filings + ≥1 broker entry naming concrete stock symbols, `evidence_gaps` no longer contains `missing_constituent_snapshot` or `constituent_not_applicable`.
2. **Idempotent cache** — second `irc run --from opportunity` on the same day reads from `data/fundamentals/{provider_report_quarter}/active_fund/fund_<iid>.json` with **zero** AkShare calls (verified via call counter); cache dir name matches `ActiveFundSnapshot.source_report_quarter`, not today's calendar date.
3. **Gold / bond / CN ETF / tracked CN indices** — every published row carries `scope="instrument"` `citation_kind="data"` evidence (NAV) AND `citation_kind="information"` evidence (announcement). No published row has only macro/policy-scoped citations.
4. **QDII** — all `qdii_us`/`qdii_hk`/`qdii_global` rows appear ONLY in the discipline failure section with `evidence_gaps=["qdii_information_unavailable"]`; never in `thesis_cards.yaml`, `memo.md` picks, or `discipline_report.md` action lines.
5. **Per-stock analysis** — every `cn_equity_fund` row has `constituent_analyses` populated for all top-N holdings (default top_N=10). The `## 持仓明细` appendix in `memo.md` lists all top-N constituents per fund with either ≥1 evidence entry or an explicit `failure_reasons` entry. Constituents with neither raise `audit_error="missing_constituent_record"`.
6. **Citation gate (block mode)** — on canonical `outputs/<date>/` paths, `IRC_CITATION_ENFORCE_MODE=warn` is rejected; the gate fires `block` regardless of env var. Uncited memo prose `[ref:bad_id]` markers raise `kind="hallucinated_citation"`. Wrong-instrument citations (valid in run but wrong `owner_instrument_id` or wrong `asset_class`) raise `kind="wrong_instrument_citation"`. Wrong-asset-class portfolio citations raise `kind="wrong_instrument_citation"` from `CitationMeta.asset_class` alone (no alias lookup needed).
7. **Rejection trace** — `outputs/<date>/rejections.json` exists and contains one entry per excluded fund with `instrument_id`, `name_cn`, `asset_class`, `rejection_reason`, `decision_rule`, full `constituent_coverage` list (weight ranks + adapter-level `failure_reasons`).
8. **V1 systematic exclusions** — `discipline_report.md` contains a once-per-run summary line near the failure section naming the count of US-heavy material-holding funds excluded (Policy B info-leg quorum + missing V1 US news adapter).
9. **Determinism** — `select_citations` produces the same 3-entry output across shuffled input orders; evidence_pool and picks_table cite the same 3 citation_ids per instrument.
10. **Test suite green** — `pytest -x` passes across all changes; live AkShare integration tests run via `pytest -m live_akshare` separately.

## Cost note

Worst-case fetch budget per canonical run: 52 × 31 (active funds) + 20 × 2 (passive) + freshness probes ≈ 1900 AkShare calls. `IRC_FETCH_BUDGET` default = 2000. Subagent dispatch budget is also non-trivial (10 items × ~9 phases each ≈ 90 dispatches; spec/grill/plan on Opus, rest on Sonnet). User has acknowledged the full-backlog scope in this turn.
