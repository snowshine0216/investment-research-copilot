Stage 0 · ingest → plan — Detailed Sub-Workflow

Stages 1–7 of `irc run` unpacked — internal phases, decisions, halt gates, artifacts · companion to overall-workflow.html (which details stages 8+9)

Data plane (§1, §2, §5)

  • • §1 ingest primes everything: instruments, prices, macro_series, nav_history, fund_metrics → DuckDB
  • • Preflight canary (AkShare 510300) fails fast on network issues before any per-instrument fetch
  • • Fatal 0%-success gate distinguishes "AkShare unreachable" from per-instrument skip
  • • §2 research is gated by RESEARCH_ENABLED; partial provider loss is warn-only, missing critical theme is fail
  • • §5 gold freshness gate reads manifest.last_run_at (≤3d) — the first downstream consumer of §1's manifest
  • • WGC CSVs + research themes are soft inputs to gold drivers — missing → fallback values + unavailable flag, never halt

Logic plane (§3, §4, §6, §7)

  • • §3 discover: hard filter → quality filter → role bucket with fail_below halt (relaxed-pool recovery applied first)
  • • §3 write_reason is the only LLM call in discovery — failure skips the row, no halt
  • • §4 score runs 5 factors per row; only macro_fit hits the LLM (parallel via ThreadPoolExecutor), failure → neutral 50
  • • §6 allocate hardcodes PER_CLASS_TOP_K=4 and role-diversity-first selection before pure score backfill
  • • §6 dedupe + correlation + satellite cap all renormalize within asset class; excess spills to cash_residual
  • • §7 mode partitions on (current_total_cny, monthly_new_capital_cny) thresholds — drives default_buy_method per asset_class

Halt gates & failure modes

  • • §1·G akshare_empty (price OR nav 0%-success) · akshare_unreachable (preflight)
  • • §2·G research_quality fail (no providers per locale · critical theme missing) → rc=2
  • • §3·G role_bucket fail_below — any role under min_candidates after relaxed-pool recovery → halt
  • • §5·G STALE_INGEST (manifest > 3d) · gold instrument missing / empty prices → warn + rc=1
  • • §5·C tilt clamp: trending_down + overweight → neutral_plus (conservative, not a halt)
  • • Pipeline level: rc≠0 OR missing required outputs → PIPELINE_HALTED.md + .pipeline_state.json (resume from last good stage)
